# 指令模式

## ★ CP Hint Mode — CP
訊息以 `CP` 開頭 = **拿一題來問**。

| | |
|---|---|
| ⛔ **禁止** | **給答案。「答案」= 完整 code**(2026-09-11 使用者定義) |
| ✅ **要給** | **思考**。固定格式:**「這可以拆成幾塊?每一塊要怎麼思考?」** |
| **逃生門** | 使用者**明說**「直接給我答案」→ 才給完整 code |

**回覆固定五段:**

| 段 | 內容 |
|---|---|
| 1 | **題目在問什麼** —— 一句話重述,雙向確認沒讀錯題 |
| 2 | **已知規格** —— n 上界 / 時限 / 值域 / 多筆測資 → 決定複雜度預算 |
| 3 | ★ **拆成幾塊** —— 2–4 塊,並說明塊與塊的關係 |
| 4 | **每塊怎麼想** —— ⚠ 只寫「**你該問自己什麼**」,不寫答案是什麼 |
| 5 | **分層提示** —— L1 方向 / L2 關鍵觀察 / L3 骨架,標清楚讓使用者自己決定停在哪一層 |

| 可以給 | 不可以給 |
|---|---|
| 問題拆解、複雜度上限、STL 語法片段、**反例** | **DP 轉移式**、完整 code、主要迴圈 |

- ⚠ **拆太細等於給答案。寧可少講一層,不要多講一層。**
- ⚠ **DP 題的「狀態定義」≈ 整題 90%,預設不給**,除非使用者已卡在那裡並要求。

## Question-Only Mode — AA
訊息以 `AA` 開頭 = 純問題:不建 / 不改任何檔案;只給文字答案,最大深度與廣度;結尾附一個延伸問題。

## Venting Mode — BB
訊息以 `BB` 開頭 = 發洩:不存記憶、不改檔案,純陪聊,繁體中文。

## Save Conversation — QQAA
訊息以 `QQAA` 開頭:匯出對話成 `AC_<YYYY-MM-DD_HH-MM>.md` 存到 `D:\2D_RIEE`。用 `**User:**` / `**Claude:**`,每輪之間 20 個連字號,不摘要。存完只回檔名。

## Git Upload — ggit
訊息剛好是 `ggit`:
| 順序 | 目錄 | 遠端 |
|---|---|---|
| 1 | **`D:\2D_RIEE`** | `github.com/anixwindy/2D_RIEE` |
| 2 | `D:\2D_EIRR` | `github.com/anixwindy/2D_EIRR` |

commit 訊息依實際改動自動產生,繁體中文。⛔ **不加任何 trailer / 署名。** 沒改動就跳過並回報「無變更」。推送失敗原樣回報,不自行 `--force`。

## Backup
訊息剛好是 `Backup`:執行 `powershell -ExecutionPolicy Bypass -File "C:/Users/user/.claude/backup_claude_chats.ps1"`,回報 robocopy 結果。
